# 金融-证券股票行业知识库

> 模板: finance-securities
> 设计文档: docs/IMPROVEMENT-PLAN.md § M4.2 D3 模板 5

> ⚠️ 合规等级：最高（金融监管 + 证券法 + 广告法三重约束）

## 概述

本目录存放金融-证券股票行业模板的知识库文档。知识库用于 AI 员工（行情分析师、投顾助理、公告摘要员）的回答增强，提供行业专业知识支撑。

知识库采用 RAG（检索增强生成）方式接入，AI 员工在回答客户问题时会自动检索相关文档片段，确保回答准确、专业、合规。

## 合规声明

⚠️ 本知识库内容严格遵守以下法律法规：
- 《中华人民共和国证券法》
- 《证券期货投资者适当性管理办法》
- 《证券投资顾问业务暂行规定》
- 《广告法》（绝对化用语禁令）
- 交易所信息披露规则

所有内容仅基于公开信息，不包含任何内幕信息。所有 AI 回复必须包含风险声明。

## 文档详细说明

### 1. 证券法规合规手册（compliance_handbook.md）

**内容要点**：
- 证券法核心条款：
  - 禁止承诺收益（第 X 条）
  - 禁止传播内幕信息（第 X 条）
  - 禁止操纵市场（第 X 条）
- 投顾业务规范：
  - 持证上岗要求
  - 适当性管理义务
  - 风险揭示义务
  - 不得推荐具体个股（非投顾场景）
- 广告法绝对化用语禁令：
  - 禁用"最""绝对""100%""保证"等
- 信息披露规则：
  - 真实性、准确性、完整性
  - 及时性、公平性
- 投资者保护：
  - 风险测评要求
  - 投诉处理流程
  - 纠纷调解机制

**使用场景**：
- AI 员工回复前的合规检查
- 客户咨询涉及合规问题时
- 培训新员工合规知识

### 2. 投顾业务流程手册（advisor_workflow.md）

**内容要点**：
- 开户流程：
  - 所需材料（身份证 + 银行卡 + 手机号）
  - 网上开户步骤（7 步）
  - 现场开户步骤
  - T+1 日开通
- 交易规则：
  - 交易时间（9:30-11:30 / 13:00-15:00）
  - T+1 制度
  - 涨跌停板（主板 ±10%，创业板/科创板 ±20%）
  - 交易单位（100 股起买）
  - 费用（佣金 + 印花税 + 过户费）
- 风险测评：
  - 测评维度（年龄/收入/投资经验/风险偏好）
  - 风险等级（保守型/谨慎型/稳健型/积极型/进取型）
  - 测评有效期（1 年）
  - 重新测评情形
- 产品匹配：
  - 产品风险等级（R1-R5）
  - 客户风险等级与产品匹配规则
  - 不匹配时的处理流程
- 投顾产品：
  - 基础投顾服务
  - 增强投顾服务
  - 私募投顾服务
  - 费率结构

**使用场景**：
- 客户咨询开户/交易/风测流程
- 投顾产品介绍
- 适当性管理检查

### 3. 公告披露规则手册（disclosure_rules.md）

**内容要点**：
- 定期报告：
  - 年报（4 月 30 日前）
  - 半年报（8 月 31 日前）
  - 季报（一季报 4 月 30 日前，三季报 10 月 31 日前）
- 临时公告：
  - 重大事项公告（董事会决议/股东大会决议）
  - 资产重组公告（重组方案/进展/完成）
  - 股权变动公告（增减持/质押/冻结）
  - 业绩预告/业绩快报
  - 监管问询函及回复
- 信息披露要求：
  - 真实性、准确性、完整性
  - 及时性、公平性
  - 简明清晰、通俗易懂
- 公告分类（客观分类）：
  - 业绩类（增长/下滑/亏损/扭亏）
  - 资产类（重组/收购/出售）
  - 股权类（增减持/质押/回购）
  - 治理类（人事变动/章程修改）
  - 监管类（问询函/监管措施/处罚）
- 摘要编写规范：
  - 关键信息提取（金额/比例/时间/对象）
  - 客观陈述，不评价投资价值
  - 标注公告来源和发布时间
  - 提示以公告原文为准

**使用场景**：
- 公告摘要员编写摘要
- 客户咨询公告内容
- 财报数据解读

### 4. 技术分析基础手册（technical_analysis.md）

**内容要点**：
- 趋势类指标：
  - MA（移动平均线）：5 日/10 日/20 日/60 日/120 日/250 日
  - MACD（指数平滑异同移动平均线）：DIF/DEA/MACD 柱
  - BOLL（布林带）：上轨/中轨/下轨
- 震荡类指标：
  - KDJ（随机指标）：K/D/J 三线
  - RSI（相对强弱指标）：6 日/12 日/24 日
  - W&R（威廉指标）
- 成交量指标：
  - OBV（能量潮）
  - VWAP（成交量加权平均价）
- 形态分析：
  - 反转形态（头肩顶/头肩底/双顶/双底）
  - 持续形态（三角形/旗形/矩形）
- 技术分析局限性：
  - 技术分析不是万能的
  - 存在滞后性
  - 受突发事件影响
  - 需结合基本面分析

**使用场景**：
- 行情分析师解读技术指标
- 客户咨询技术分析问题
- 培训新员工技术分析知识

## 知识库接入方式

### RAG 检索流程

```
客户问题 → Embedding 向量化 → 知识库向量检索 → Top-K 相关片段 → 拼接 Prompt → LLM 生成回答
```

### 文档格式要求

- 使用 Markdown 格式
- 每个文档不超过 5000 字（超出需拆分）
- 使用清晰的标题层级（H1/H2/H3）
- 关键信息用表格/列表呈现
- 避免冗长描述，突出可操作信息
- 数据必须标注来源和时间

### 更新维护

- 证券法规：法规变更时更新
- 业务流程：流程变更时更新
- 公告规则：披露规则变更时更新
- 技术分析：相对稳定，按需更新
- 板块分类：跟随行业分类调整更新

## 合规要点

知识库内容必须遵守以下合规要求：

1. **不推荐个股**：所有内容不涉及具体个股推荐
2. **不承诺收益**：不出现"保证收益""稳赚"等承诺
3. **不传播内幕**：仅基于公开信息，不引用未公开信息
4. **不预测点位**：不出现具体点位预测
5. **不使用禁用词**：稳赚、一定涨、保证收益、内幕、庄家等
6. **必须标注来源**：所有数据标注来源和时间
7. **必须声明风险**：涉及投资话题必须提示风险
8. **客观陈述**：不评价投资价值，不主观判断
