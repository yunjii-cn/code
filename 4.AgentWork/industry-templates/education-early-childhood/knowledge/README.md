## 概述

本目录存放教育-早教行业模板的知识库文档。知识库用于 AI 员工（育儿顾问、课程顾问、故事老师）的回答增强，提供 0-6 岁早教领域的专业知识支撑。

知识库采用 RAG（检索增强生成）方式接入，AI 员工在回答家长问题时会自动检索相关文档片段，确保回答准确、专业、合规。

⚠️ **本行业涉及婴幼儿健康与安全，知识库内容必须严谨**：
- 发育里程碑以 WHO 标准为依据
- 疫苗接种以国家免疫规划为依据
- 任何症状/疾病问题引导就医，不替代医生
- 不推荐具体药品，用药遵医嘱

## 文档详细说明

### 1. 0-6岁发育里程碑（development_milestones.md）

**内容要点**：
- 依据：WHO 儿童生长发育标准 + 国家卫健委《0-6岁儿童健康管理规范》
- 五大发育领域：
  - 大运动（抬头/翻身/坐/爬/站/走/跑/跳）
  - 精细动作（抓握/捏/串珠/握笔/剪刀）
  - 语言（理解/表达/词汇/句子/对话）
  - 社交（眼神/微笑/互动/合作/规则）
  - 认知（探索/因果/分类/解决问题）
- 分月龄里程碑（1/3/6/9/12/18/24/36/48/60/72月）
- 预警信号（需就医评估的发育落后表现）
- 个体差异说明（每个宝宝不同，范围有宽窄）

**使用场景**：
- 家长咨询"宝宝X个月还不会XX正常吗"
- 家长咨询"宝宝发育是不是落后"
- 课程顾问根据发育阶段推荐课程
- 故事老师根据年龄推荐内容

### 2. 辅食添加指南（feeding_guide.md）

**内容要点**：
- 依据：WHO/国家卫健委婴幼儿喂养指南
- 添加时机：满6个月 + 4个 readiness 信号
- 分阶段指南：
  - 6-7月：强化铁米粉 + 单一蔬菜泥/果泥
  - 7-9月：蛋黄/肉泥/鱼泥 + 增加质地（泥→碎末）
  - 9-12月：手指食物 + 软烂块状 + 自主进食练习
  - 1-2岁：三餐两点 + 家庭饮食（少盐少糖）
  - 2-3岁：均衡饮食 + 培养饮食习惯
- 添加原则：由稀到稠、由少到多、由单一到多样、每次一种新食物观察3-5天
- 常见过敏原：牛奶/鸡蛋/花生/坚果/鱼/贝类/大豆/小麦
- 营养重点：铁/锌/钙/维生素D/DHA
- 禁忌：1岁内不加盐糖蜂蜜、不喝鲜牛奶、不吃整粒坚果

**使用场景**：
- 家长咨询"什么时候添加辅食"
- 家长咨询"第一次辅食吃什么"
- 家长咨询"X个月宝宝能吃XX吗"
- 家长咨询"宝宝挑食/便秘怎么办"

### 3. 疫苗接种时间表（vaccine_schedule.md）

**内容要点**：
- 依据：国家免疫规划疫苗儿童免疫程序
- 一类疫苗（免费/强制）：
  - 乙肝疫苗：出生/1月/6月
  - 卡介苗：出生
  - 脊灰疫苗：2月/3月/4月
  - 百白破疫苗：3月/4月/5月/18月
  - 麻腮风疫苗：8月/18月
  - 乙脑疫苗：8月/2岁
  - A群流脑疫苗：6月/9月
  - A+C群流脑疫苗：3岁/6岁
  - 甲肝疫苗：18月
- 二类疫苗（自费/自愿）：
  - 13价肺炎、轮状病毒、Hib、手足口EV71、流感、水痘、狂犬病
- 接种禁忌：发热/急性病/严重过敏/免疫缺陷
- 接种前后注意事项
- 常见反应处理（低热/红肿/烦躁）
- 异常反应就医指征（高热/持续哭闹/抽搐）

**使用场景**：
- 家长咨询"疫苗时间表"
- 家长咨询"自费疫苗有必要吗"
- 家长咨询"打完疫苗发烧怎么办"
- 家长咨询"疫苗可以推迟吗"

### 4. 早教课程体系（curriculum_system.md）

**内容要点**：
- 蒙台梭利课程：
  - 理念：以儿童为中心，尊重敏感期，预备环境
  - 适合年龄：0-6岁
  - 核心区域：日常生活/感官/数学/语言/科学文化
  - 特色：混龄/教具操作/自主选择
- 感统训练课程：
  - 理念：通过感觉统合训练促进大脑发育
  - 适合年龄：0-6岁（重点1-4岁）
  - 核心内容：前庭觉/本体觉/触觉训练
  - 特色：大运动游戏/平衡训练/协调训练
- 音乐课程：
  - 理念：通过音乐启蒙促进语言/社交/情感发展
  - 适合年龄：0-6岁
  - 核心内容：节奏/旋律/乐器/律动
  - 特色：亲子互动/奥尔夫音乐/中外儿歌
- 亲子课程：
  - 理念：促进亲子依恋，指导家长育儿
  - 适合年龄：0-3岁
  - 核心内容：亲子游戏/抚触/互动
  - 特色：家长参与/育儿指导/社交互动
- 课程选择建议：根据年龄/兴趣/发育阶段/家庭需求
- 课程效果说明：每个宝宝不同，不承诺具体效果

**使用场景**：
- 课程顾问推荐课程
- 家长咨询"有什么课程"
- 家长咨询"课程内容是什么"
- 故事老师了解课程背景

### 5. 常见育儿问题（common_issues.md）

**内容要点**：
- 夜啼/睡眠问题：
  - 原因：生理需求/出牙/分离焦虑/过度刺激/肠绞痛
  - 处理：排查需求/记录规律/睡前仪式/睡眠安全
  - 就医指征：持续哭闹/伴随症状/发育异常
- 挑食/喂养问题：
  - 原因：口味偏好/自主意识/食物过敏/进餐氛围
  - 处理：不强迫/多次尝试/家长示范/参与准备
  - 就医指征：体重下降/营养缺乏/吞咽困难
- 情绪/行为问题：
  - 打人/咬人：温和制止/表达情绪/正确示范
  - 发脾气：共情/冷处理/转移注意
  - 分离焦虑：高质量陪伴/告别仪式/逐步分离
- 社交问题：
  - 不分享：正常发展阶段/不强迫/示范
  - 怕生：正常表现/逐步接触/不强迫
  - 打架：制止/引导表达/教解决方法
- 如厕训练：
  - 时机：18-24个月 + readiness 信号
  - 方法：选择夏天/固定马桶/表扬鼓励
  - 就医指征：4岁白天不能控制
- 安全要点：
  - 睡眠安全：仰睡/硬床垫/无松软物品
  - 乘车安全：安全座椅/反向安装至2岁
  - 防窒息：远离小物件/食物切小块
  - 防坠：窗户防护/楼梯门栏

**使用场景**：
- 家长咨询"宝宝夜啼怎么办"
- 家长咨询"宝宝挑食怎么办"
- 家长咨询"宝宝爱打人怎么办"
- 家长咨询"宝宝太粘人怎么办"
- 家长咨询"如厕训练"

## 知识库接入方式

### RAG 检索流程

```
家长问题 → Embedding 向量化 → 知识库向量检索 → Top-K 相关片段 → 拼接 Prompt → LLM 生成回答
```

### 文档格式要求

- 使用 Markdown 格式
- 每个文档不超过 5000 字（超出需拆分）
- 使用清晰的标题层级（H1/H2/H3）
- 关键信息用表格/列表呈现
- 发育里程碑/疫苗时间表用表格呈现
- 避免冗长描述，突出可操作信息

### 更新维护

- 发育里程碑：依据 WHO/国家卫健委标准更新，相对稳定
- 辅食添加指南：依据喂养指南更新，相对稳定
- 疫苗接种时间表：国家免疫规划调整时更新
- 早教课程体系：课程调整时更新
- 常见育儿问题：根据家长反馈持续补充

## 合规要点

知识库内容必须遵守以下合规要求：

1. **不替代医生**：任何症状/疾病问题引导就医，不提供诊断
2. **不推荐药品**：用药建议遵医嘱，不推荐具体药品
3. **不评判家长**：尊重每个家庭的选择，不站队育儿分歧
4. **不焦虑营销**：不制造"错过关键期"恐慌，每个宝宝不同
5. **安全严谨**：睡眠/乘车/用电/防坠等安全问题按权威指南
6. **禁用词**：必须、应该、不然就晚了
7. **必须词**：根据发育、建议咨询医生、每个宝宝不同
