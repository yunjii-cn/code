## 概述

本目录存放电商-穿搭行业模板的知识库文档。知识库用于 AI 员工（穿搭搭配师、售后客服、内容运营）的回答增强，提供行业专业知识支撑。

知识库采用 RAG（检索增强生成）方式接入，AI 员工在回答客户问题时会自动检索相关文档片段，确保回答准确、专业、合规。

## 文档详细说明

### 1. 尺码对照表（size_chart.md）

**内容要点**：
- 女装尺码对照（S/M/L/XL/XXL）：身高、体重、胸围、腰围、臀围对应表
- 男装尺码对照（S/M/L/XL/XXL）：身高、体重、胸围、腰围对应表
- 童装尺码对照（80-160 码）：年龄、身高、体重对应表
- 鞋类尺码对照（女鞋 35-40 / 男鞋 39-46）：脚长、脚围对应表
- 内衣尺码对照（A/B/C/D 罩杯）：下胸围、上胸围对应表
- 国际尺码转换（中国/欧盟/美国/日本）

**使用场景**：
- 客户咨询"我身高 X 体重 Y 穿什么码"
- 客户咨询"鞋子偏大偏小"
- 客户咨询"童装 X 码适合多大孩子"

### 2. 面料知识手册（fabric_knowledge.md）

**内容要点**：
- 棉（Cotton）：透气吸汗、亲肤、易皱、缩水率 3-5%
- 麻（Linen）：透气凉爽、易皱、硬挺、适合夏季
- 丝（Silk）：丝滑透气、垂感好、娇贵需手洗、不可暴晒
- 毛（Wool）：保暖性好、易起球、需干洗、防蛀
- 化纤（Polyester/Nylon）：耐磨抗皱、透气性差、易静电
- 混纺面料特性
- 洗涤保养指南：
  - 水温要求（30°C / 40°C / 冷水）
  - 洗涤方式（机洗/手洗/干洗）
  - 晾晒方式（悬挂/平铺/阴干）
  - 禁忌（漂白/暴晒/高温）

**使用场景**：
- 客户咨询"这件衣服是什么面料"
- 客户咨询"会起球吗/会缩水吗"
- 客户咨询"怎么洗涤保养"

### 3. 场景搭配指南（style_guide.md）

**内容要点**：
- 通勤搭配：白衬衫+西裤、针织衫+半裙、西装+连衣裙
- 约会搭配：碎花连衣裙+小白鞋、针织裙+长靴、半身裙+毛衣
- 宴会搭配：香槟色连衣裙+高跟鞋、小黑裙+珍珠配饰、套装+手拿包
- 亲子搭配：同款不同色 T 恤、同色系连衣裙、同款卫衣
- 度假搭配：碎花连衣裙+草帽、阔腿裤+吊带、半身裙+T 恤
- 风格分类：韩系/日系/欧美/国潮/复古/极简
- 色彩搭配原则：同色系/对比色/邻近色

**使用场景**：
- 客户咨询"参加婚礼穿什么"
- 客户咨询"通勤怎么穿"
- 客户咨询"约会穿什么好看"

### 4. 退换货政策（return_policy.md）

**内容要点**：
- 7 天无理由退货：
  - 商品未洗涤未穿着，吊牌完整
  - 不影响二次销售
  - 运费承担：买家承担（非质量问题）
- 15 天质量问题：
  - 破损/脱线/色差/走丝
  - 全额退款 + 承担运费
  - 需提供照片凭证
- 不支持退换货的商品：
  - 贴身衣物（内衣/泳装/袜子）
  - 定制商品
  - 清仓特价商品（需提前告知）
  - 已洗涤/已穿着/已修改商品
- 退款时效：
  - 收到退货后 1-3 个工作日原路退回
  - 大额退款（>500 元）转人工处理
- 投诉升级：
  - 争议 > 2 次升级主管
  - 评价 1-2 星通知店长

**使用场景**：
- 客户咨询"能退货吗/能换货吗"
- 客户咨询"退款多久到账"
- 客户投诉质量问题

### 5. 季节性话术手册（seasonal_scripts.md）

**内容要点**：
- 春夏上新（3-6 月）：
  - 突出新品、潮流、清爽
  - 关键词：春日必备、清新、显白、显瘦
- 秋冬上新（9-12 月）：
  - 突出保暖、质感、层次
  - 关键词：温暖、高级感、百搭
- 双 11/双 12 大促：
  - 突出优惠、囤货、限时
  - 关键词：全年最低价（注：不能用"最"，改用"超值"）、限时、抢购
- 春节/元旦：
  - 突出拜年、红色、喜庆
  - 关键词：新年战袍、红色、喜庆、拜年
- 情人节/七夕：
  - 突出约会、浪漫、甜美
  - 关键词：约会穿搭、浪漫、甜美
- 母亲节/儿童节：
  - 突出亲子、温馨、礼物
  - 关键词：亲子装、妈妈装、礼物

**使用场景**：
- 内容运营撰写季节性文案
- 客服应答季节性咨询
- 活动策划参考

## 知识库接入方式

### RAG 检索流程

```
客户问题 → Embedding 向量化 → 知识库向量检索 → Top-K 相关片段 → 拼接 Prompt → LLM 生成回答
```

### 文档格式要求

- 使用 Markdown 格式
- 每个文档不超过 5000 字（超出需拆分）
- 使用清晰的标题层级（H1/H2/H3）
- 关键信息用表格/列表呈现
- 避免冗长描述，突出可操作信息

### 更新维护

- 季节性话术：每季度更新一次
- 尺码对照表：新增品牌时更新
- 退换货政策：政策变更时更新
- 面料知识：相对稳定，按需更新
- 搭配指南：跟随潮流趋势更新

## 合规要点

知识库内容必须遵守以下合规要求：

1. **不夸大功效**：服装类商品不涉及医美/减肥/美白等功效
2. **不承诺面料**：以商品水洗标为准，不替消费者做鉴定
3. **不保证正品**：不使用"保证正品""假一赔十"等绝对化用语
4. **不使用禁用词**：最便宜、绝对、100%、保证正品等
5. **不诋毁竞品**：不对比不诋毁其他商家
