# M6.2 全民可用 · 任务分解（W5-W9）

> **目标**：把自进化内核变成全民可用产品能力，落地 `work_mode.rs`、进化仪表盘、无代码工具构建器，并打包工程化 Skill。
> **周期**：5 周 / 25 个工作日

---

## W5：`work_mode.rs`（五种工作模式）

| Day | 任务 | 产出 | 验收 |
|---|---|---|---|
| D1 | 定义 `WorkMode` 枚举（学习/教学/协作/自动/审批） | `src/work_mode.rs` | 编译通过 |
| D2 | 定义模式元数据：权限、速度、解释强度、是否需审批 | mode config | 可序列化 |
| D3 | 将模式注入 PromptBuilder | 集成 | prompt 可感知模式 |
| D4 | 审批模式接入 Plan/Execute 两阶段状态机 | 审批流 | 模式切换可用 |
| D5 | 接入前端设置项 / 会话维度切换接口 | Tauri/前端 API | UI 可切换 |

---

| Day | 任务 | 产出 | 验收 |
