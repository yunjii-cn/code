# 模板自定义指南

> **目的**：帮助用户基于 5 核心模板或从空白创建公司专属的行业模板。
> **生效日期**：2026-06-19
> **配套**：[IMPROVEMENT-PLAN.md](IMPROVEMENT-PLAN.md) § M4.2 D6、[TEMPLATE-MARKET-GUIDE.md](TEMPLATE-MARKET-GUIDE.md)

---

## 1. 概述

云集提供 5 个核心行业模板（电商穿搭 / 电商电子 / 教育早教 / 教育素质 / 金融证券），但每个公司的业务流都不一样。**模板自定义向导**让你能：

- **Fork 核心模板**：基于现有模板快速定制
- **从空白创建**：完全自定义行业（如汽车 4S 店 / 餐饮 / 房产）
- **私有 / 公开**：私有模板公司内部用，公开模板可提交市场赚分成
- **YAML 导出 / 导入**：团队复用 + 跨公司分享

### 1.1 核心价值

| 场景 | 5 内置模板 | + 自定义向导 |
|------|:---:|:---:|
| 通用行业（穿搭 / 早教） | ✅ 直接用 | ✅ 可微调 |
| 细分行业（西装 / 留学） | ❌ 不覆盖 | ✅ Fork 定制 |
| 完全新行业（4S 店 / 餐饮） | ❌ 不覆盖 | ✅ 空白创建 |
| 公司专属业务流 | ❌ 无法适配 | ✅ 完全自定义 |
| **B 端覆盖率** | **50%** | **100%** |

## 2. 6 步打造专属模板

### 2.1 进入向导

在模板市场首页右上角点击 **"自定义模板"** 按钮（Wand2 图标），进入 6 步向导。

### 2.2 Step 1：选择起点

三种起点：

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| **Fork 核心模板** | 基于 5 个核心模板创建定制版 | 业务接近核心行业，需微调 |
| **从空白创建** | 完全从零开始 | 5 核心未覆盖的新行业 |
| **从社区市场安装** | 跳转到市场浏览社区模板 | 想基于社区模板改造 |

**推荐**：优先 Fork 核心模板，可继承成熟的员工定义和规则。

### 2.3 Step 2：定义员工

配置模板元信息和员工列表。

**模板元信息**：
- 模板 ID（唯一标识，小写字母 + 数字 + 短横线）
- 模板名称（显示名称）
- 版本号（语义化版本 x.y.z）
- 行业（ecommerce / education / finance / custom）
- 描述

**员工定义**：
- 员工 ID（唯一）
- 名称（如"客服" / "搭配师"）
- 角色（如 answer_questions / fashion_advisor）
- 描述（员工职责说明）

**示例**：基于电商-穿搭 Fork 后，添加"量体师"员工：
```
ID: tailor
名称: 量体师
角色: body_measurement
描述: 西装量体咨询 + 尺码推荐
```

### 2.4 Step 3：上传知识库

上传领域知识文档，让 AI 员工更专业。

**支持的文件类型**：
- PDF (.pdf)
- Word (.doc / .docx)
- Excel (.xls / .xlsx)
- 文本 (.txt / .md)
- 网页 URL

**建议**：
- 至少上传 1 个知识库文档
- 文档内容与员工职责相关
- 避免上传过大文件（建议 < 10MB）

**示例**：西装定制公司可上传：
- `fabric_guide.md`（面料知识）
- `size_chart.xlsx`（尺码对照表）
- `care_instructions.pdf`（保养指南）

### 2.5 Step 4：配置规则

规则用于约束员工行为，确保合规和质量。

**规则字段**：
- 关键词（逗号分隔，触发规则的关键词）
- 动作（4 种）：
  - `append`：在回答末尾追加消息
  - `prepend`：在回答开头插入消息
  - `refuse`：拒绝回答
  - `replace`：用消息替换原回答
- 消息内容
- 启用 / 禁用

**示例规则**：

| 关键词 | 动作 | 消息 |
|--------|------|------|
| 投资, 收益, 涨跌 | append | 本回答仅供参考，不构成投资建议。 |
| 投诉, 差评 | prepend | 非常抱歉给您带来不便，我将立即为您处理。 |
| 内部, 机密 | refuse | （不回答，转人工） |

**金融行业特别提示**：必须配置合规规则，避免违规推荐股票。

### 2.6 Step 5：录入话术

提供 few-shot 示例对话，帮助 AI 学习你公司的回复风格。

**话术字段**：
- 用户输入
- 期望回复
- 标签（可选，如售前 / 售后 / 投诉）

**建议**：
- 至少 3 条示例
- 覆盖主要业务场景（售前咨询 / 售后处理 / 投诉应对）
- 回复风格保持一致（友好 / 专业 / 严肃）

**示例**：

| 用户输入 | 期望回复 | 标签 |
|----------|----------|------|
| 这件西装可以机洗吗？ | 这件西装建议干洗，机洗可能导致面料变形。如需清洁服务，可预约我们的上门取送。 | 售前 |
| 收到的衣服尺码不对 | 非常抱歉，请提供订单号，我们将在 24 小时内为您办理换货，运费由我们承担。 | 售后 |

### 2.7 Step 6：跑评估 + 发布

#### 完整性检查

系统自动检查 8 项：
- 模板信息（ID / 名称 / 版本）
- 员工定义（≥1 个）
- 知识库（≥1 个文档）
- 话术示例（≥3 条）
- 规则配置
- 行业适配
- 版本号格式
- 描述填写

#### 评估结果

基于话术示例自动生成评估用例，评分维度：
- 响应准确性
- 角色匹配度
- 规则遵循度

#### 可见性设置

| 选项 | 说明 |
|------|------|
| **私有** | 公司内部使用，不进入社区市场 |
| **公开** | 可一键提交到社区市场，让其他公司使用 |

**建议**：
- 公司专属业务流 → 私有
- 通用行业方案 → 公开（可赚 70% 分成）

#### 导出 / 提交

- **导出 YAML**：下载模板文件到本地，可导入其他云集实例
- **提交到社区市场**：跳转到提交向导，走审核流程

## 3. 私有模板隔离

### 3.1 私有模板特点

- ✅ 公司内部使用，不进入社区市场
- ✅ 不会泄露给其他公司
- ✅ 可在公司团队内共享
- ❌ 不能赚取分成

### 3.2 公开模板特点

- ✅ 可提交到社区市场
- ✅ 付费模板享 70% 分成
- ⚠️ 内容公开，所有用户可见
- ⚠️ 需通过自动 + 人工审核

### 3.3 切换可见性

- 私有 → 公开：随时可切换，提交市场审核
- 公开 → 私有：需先下架市场中的模板

## 4. 模板导入 / 导出

### 4.1 导出 YAML

在 Step 6 点击 **"导出 YAML"** 按钮，下载 `{模板ID}-{版本号}.yaml` 文件。

**YAML 文件结构**：

```yaml
# 云集智能体工作台 - 自定义模板
# 生成时间: 2026-06-19T10:00:00Z
# 可见性: 私有（公司内部）

id: ecommerce-fashion-custom-abc123
name: 电商-穿搭-定制版
version: 1.0.0
industry: ecommerce
sub_industry: fashion
description: 基于电商-穿搭模板定制
visibility: private
based_on: ecommerce-fashion

employees:
  - id: customer_service
    name: 客服
    role: answer_questions
    description: 售前售后咨询
  - id: fashion_advisor
    name: 搭配师
    role: fashion_advisor
    description: 穿搭风格推荐
  - id: tailor
    name: 量体师
    role: body_measurement
    description: 西装量体咨询

knowledge:
  - name: fabric_guide.md
    type: text
    size: 10240
  - name: size_chart.xlsx
    type: excel
    size: 5120

rules:
  - keywords: [投资, 收益]
    action: append
    message: 本回答仅供参考。
    enabled: true

speeches:
  - user: 这件西装可以机洗吗？
    assistant: 这件西装建议干洗...
    tag: 售前
```

### 4.2 导入 YAML

在模板市场点击 **"自定义模板"** → Step 1 选择"从空白创建" → Step 2 粘贴 YAML 内容（即将支持）。

### 4.3 团队复用

- 导出 YAML → 发送给同事
- 同事导入 YAML → 立即获得相同模板
- 适合多门店 / 多分公司的统一模板部署

## 5. 版本管理

### 5.1 语义化版本

格式：`主版本.次版本.修订号`（x.y.z）

| 版本变化 | 说明 | 示例 |
|----------|------|------|
| 修订号 +1 | 修复 bug / 小调整 | 1.0.0 → 1.0.1 |
| 次版本 +1 | 新增功能 / 员工 | 1.0.0 → 1.1.0 |
| 主版本 +1 | 重大重构 / 不兼容 | 1.0.0 → 2.0.0 |

### 5.2 公司内部迭代

**典型迭代节奏**：
- V1.0.0：初版上线，用 3 个月
- V1.1.0：根据使用反馈新增员工 / 话术
- V1.2.0：补充知识库文档
- V2.0.0：业务流重大调整

### 5.3 社区模板升级

如果你 fork 了社区模板，原作者更新后会收到通知：
- 查看变更内容
- 选择是否合并到你的定制版
- 保留你的自定义修改

## 6. 示例场景

### 场景 1：西装定制公司

**起点**：Fork 电商-穿搭
**定制**：
- 添加员工：量体师（body_measurement）
- 上传知识库：面料指南 / 尺码表 / 保养说明
- 配置规则：检测"机洗"关键词时建议干洗
- 录入话术：量体咨询 / 面料推荐 / 保养问答
**可见性**：私有（公司专属业务流）

### 场景 2：汽车 4S 店

**起点**：从空白创建
**定制**：
- 员工：销售顾问 / 试驾预约 / 保养提醒
- 知识库：车型参数 / 保养周期 / 金融方案
- 规则：检测"降价"时转人工
- 话术：车型对比 / 试驾流程 / 保养咨询
**可见性**：私有

### 场景 3：留学机构

**起点**：Fork 教育-早教
**定制**：
- 添加员工：留学顾问
- 修改员工：故事老师 → 外教
- 知识库：院校信息 / 签证流程 / 语言考试
**可见性**：公开（提交市场赚分成）

### 场景 4：律所

**起点**：Fork 金融-证券
**定制**：
- 修改员工：风险测评 → 案件分类
- 知识库：法律法规 / 案例库
- 规则：检测"具体建议"时声明"非正式法律意见"
**可见性**：私有

## 7. 常见问题

### Q1：Fork 的模板可以修改多少？

A：所有内容都可修改，包括员工 / 知识库 / 规则 / 话术。Fork 只是起点，最终模板完全属于你。

### Q2：私有模板会被平台看到吗？

A：不会。私有模板存储在本地，不会上传到平台服务器。只有你选择"公开"并提交审核后，平台才会看到内容。

### Q3：可以基于其他公司的公开模板 Fork 吗？

A：可以。在模板市场找到喜欢的模板，安装后基于它自定义。但需遵守原作者的许可协议。

### Q4：导出的 YAML 可以编辑吗？

A：可以。YAML 是纯文本，可用任何编辑器修改。修改后可导入回系统。

### Q5：模板可以回滚到旧版本吗？

A：可以。每个导出的 YAML 都包含版本号，可导入旧版本 YAML 回滚。

### Q6：如何分享私有模板给同事？

A：导出 YAML → 发送文件 → 同事导入。同事需使用云集智能体工作台。
