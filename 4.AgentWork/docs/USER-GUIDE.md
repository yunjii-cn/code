## 1. AI 互动面板

**入口**：侧边栏第 1 个图标（MessageSquare），默认首页。

### 基本用法

1. 在底部输入框输入需求
2. 按 **Enter** 发送（Shift+Enter 换行）
3. AI 思考过程实时显示（流式输出）
4. 完成后 AI 回复显示在对话区

### 多轮对话

- 系统自动维护最近 6 轮对话上下文
- 每次发送时上下文随请求一起传递给 AI
- 点击顶部"清空"按钮可重置对话

### 任务触发

输入包含以下关键词的消息会自动跳转到任务看板：
- 修这个 / 创建任务 / 建任务 / 加任务 / 拆任务 / 新建任务 / 添加任务

### 中断生成

- 生成过程中"发送"按钮变为"停止"（红色）
- 点击"停止"可中断当前生成

### 消息状态

- 发送中（旋转图标）
- 已发送（对勾图标）
- 失败（红色感叹号）

## 2. 任务看板

**入口**：侧边栏第 6 个图标（ClipboardList）。

### 规划工作流

1. 在顶部输入框输入需求
2. 点击"规划"按钮
3. 系统生成 DAG（任务依赖图）
4. 任务按拓扑层级展示

### 调度控制

| 按钮 | 功能 |
|------|------|
| 推进一步 | 执行下一个可运行的任务 |
| 报告完成 | 标记任务为已完成 |
| 报告合并 | 标记任务为已合并 |
| 验证失败 | 标记任务验证失败 |
| 报告失败 | 标记任务执行失败 |
| 重置 | 清空当前工作流 |

### 任务状态

| 状态 | 颜色 | 说明 |
|------|------|------|
| Pending | 灰色 | 等待依赖完成 |
| Running | 蓝色 | 正在执行 |
| Verifying | 琥珀色 | 等待验收 |
| Merged | 绿色 | 已合并完成 |
| Failed | 红色 | 执行失败 |
| Rejected | 红色 | 验收未通过 |

## 3. 交付物预览

**入口**：`/delivery` 路由（或任务合并后自动弹出）。

### 功能

- **Commit Message**：展示 AI 生成的 commit 描述
- **文件变更**：diff 对比（可折叠），显示增删行
- **测试结果**：通过/失败/跳过/覆盖率 + 详细列表
- **Approve**：通过验收（测试全通过时可用）
- **Request Changes**：请求修改，任务退回

## 4. 团队协作

**入口**：侧边栏第 5 个图标（Users）。

### 内置团队模板

| 模板 | 角色数 | 说明 |
|------|:---:|------|
| fullstack | 4 | PM + 后端 + 前端 + 测试 |
| backend | 3 | PM + 后端 + 测试 |
| solo | 1 | 单人全栈 |

### 模型配置

1. 点击"注册模型"
2. 填写模型 ID / Provider / Base URL / API Key
3. 内置支持：Qwen / GLM / MiniMax / Claude / GPT

## 5. 时间轴与快照

## 7. 语义搜索

**入口**：侧边栏第 4 个图标（Search）。

### 功能

## 8. 设置

**入口**：侧边栏最后一个图标（Settings）。

### AI 配置

- API Key
- Base URL
- 模型名称
- Temperature / Max Tokens

### Git 模式

| 模式 | 说明 |
|------|------|
| Stealth | 纯本地，不推送到 git |
| Sync | 自动镜像到 git |
| Release | 只推正式版本 |

## FAQ

**Q: 如何自定义 AI 员工？**
A: 详见 [AI 员工定义指南](EMPLOYEE-GUIDE.md)。

**Q: 如何接入自己的 LLM？**
A: 在设置中配置 API Key + Base URL，或注册自定义模型。

**Q: 数据存储在哪里？**
A: 本地 SQLite + YAML 文件（`.yunji/` 目录），不依赖云端。

**Q: 如何备份数据？**
A: 复制 `.yunji/` 目录即可。M4.1 会增加云端备份功能。
