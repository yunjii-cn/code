# 云集双字母 App Icon 规则

> 状态：v1 草案  
> 首个落地：AgentWork / AW  
> 用途：为 AW、LH、WB、AI 等双字母产品生成同一体系的矢量图标

## 1. 基础网格

- 画布：`100 x 100`
- 外框：`x=4 y=4 width=92 height=92 rx=22`
- 内容安全区：`18 <= x <= 82`，`20 <= y <= 80`
- 主笔画宽度：`9.5`，小尺寸不可低于 `8`
- 辅助线宽度：`3.5-4`
- 端点：`stroke-linecap="round"`
- 转角：`stroke-linejoin="round"`

## 2. 外形

默认使用圆角方形 App Icon，不使用圆形、六边形或复杂多边形。

原因：

- 更符合桌面、移动端、网站 favicon 的通用图标容器。
- 和 Photoshop 类软件图标处在同一识别类别，但 AW 用几何 monogram 区分。
- 后续双字母产品能保持系列化。

## 3. 双字母结构

采用“字母骨架 + 负空间连接”的方式，不使用字体转曲。优先生成填充式几何 monogram，描边式只用于早期探索或无法模板化的字母 fallback。

- 第一字母占左侧主重心。
- 第二字母占右侧主重心。
- 两字母必须共享至少一个视觉连接点。
- 字母可以被抽象，但不能完全丢失识别。
- 小尺寸优先保留外轮廓、主斜线、中心连接，删减装饰。
- 单个产品主图标必须能被还原为一个纯色 path；如果必须依赖渐变、描边或节点才成立，说明符号还不成熟。

AW 的主方案使用 `Agent Grid`：

- `A`：由左侧实体斜面、中心竖向折面和横向负空间形成。
- `W`：与 `A` 共享中心折面，再向右展开成二级折线。
- 三个节点：左上、中心、底部，只做弱提示，继承云集三柱记忆点但不喧宾夺主。
- 主图标优先使用填充式几何 monogram，描边式只作为生成器的通用 fallback。

## 4. 可复用设计语法

每个双字母产品按以下顺序出图：

1. **骨架**：先把两个字母压缩到 `18..82` 安全区，建立左主重心、右副重心、中心共享折面。
2. **填充**：把骨架扩展为实体面，不直接使用字体轮廓；端点和内角需要做光学修正。
3. **负空间**：用背景色切出横杠、字母分界或内部孔洞；负空间面积不低于主形的 `8%`，避免糊成白块。
4. **弱继承**：每个图标最多保留 2-3 个小节点或结构记忆点；节点不能成为主识别。
5. **降级**：输出 `main / mono / small` 三版。`small` 删除高光、辅助线、节点，只保留外框和纯白主形。

## 5. 高级感原则

高级感不靠复杂装饰，而靠以下约束：

- **单一主轮廓**：第一眼看到的是一个完整符号，而不是两个字母拼贴。
- **负空间可解释**：横杠、内角和字母分界通过背景色间隙形成，不额外堆装饰线。
- **光学补偿**：左右边界略不对称，右侧 W 更宽一点，抵消 W 天然视觉重量不足。
- **小尺寸优先**：16px 时保留外轮廓和中心折线，节点和高光可以消失。
- **母品牌弱继承**：继承“三点/三柱”的记忆，不直接复用红色云形。
- **单色可用**：去掉渐变、节点和高光后，白色符号仍能独立成立。

## 6. 配色

每个产品只指定一个主品牌色，图标内部默认使用白色 monogram。

AgentWork：

- 主色：`#1E6CF0`
- 深色：`#1553C7`
- 浅色：`#5B9BFF`
- 字标：`#FFFFFF`
- 辅助高光：`#DCEBFF`

## 7. 输出标准

每个产品至少输出：

- `<产品短名>-agent-grid.svg`：主方案
- `<产品短名>-agent-grid-mono.svg`：单色 monogram
- `<产品短名>-agent-grid-small.svg`：小尺寸纯色版
- `<产品短名>-fold.svg`：折叠感备选
- `<产品短名>-cloud-core.svg`：母品牌继承备选
- `preview.html`：16/32/64/128/256 尺寸预览

AW 已落地文件（`<产品短名>` = `aw`）：

- `aw-agent-grid.svg`
- `aw-agent-grid-mono.svg`
- `aw-agent-grid-small.svg`
- `aw-fold.svg`
- `aw-cloud-core.svg`
- `preview.html`

## 8. 判断标准

- 16px 能看出不是普通字母贴图。
- 32px 能看出双字母结构。
- 64px 能看出品牌结构和高级感。
- 深色、浅色背景都成立。
- 去掉渐变后，纯色版仍可识别。
