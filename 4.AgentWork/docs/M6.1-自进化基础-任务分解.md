# M6.1 自进化基础 · 任务分解（W1-W4）

> **目标**：落地 4 个核心基础模块：`memory.rs`、`sessions.rs`、`skills_v2.rs`、`prompt_builder.rs`，并补充 `tool_provider.rs` 协议抽象。
> **周期**：4 周 / 20 个工作日
> **配套**：[AW-降维打击-zcode融合增强版-v2.md](AW-降维打击-zcode融合增强版-v2.md)

---

## W1：`memory.rs`（长期记忆层）

| Day | 任务 | 产出 | 验收 |
|---|---|---|---|
| D1 | 定义 `MemoryLayer` / `MemoryEntry` / `MemoryStore` 数据结构 | `src/memory.rs` | `cargo check` 通过 |
| D2 | 设计三层记忆：事实 / 偏好 / 程序性线索 | 同上 | 结构可序列化 |
| D3 | 实现 JSON 持久化与加载 | `load/save` API | 单测通过 |
| D4 | 实现记忆合并 / 去重 / 优先级覆盖 | merge API | 5+ 用例 |
| D5 | 接入 `EmployeeDefinition` / `Profile` 维度索引 | 集成接口 | 员工可读个人记忆 |

**验收**：用户、团队、员工三级记忆能保存/读取/合并，git 可跟踪。

## W2：`sessions.rs`（会话历史层）

| Day | 任务 | 产出 | 验收 |
|---|---|---|---|
| D1 | 定义 `SessionRecord` / `TurnRecord` / `ToolCallTrace` | `src/sessions.rs` | 编译通过 |
| D2 | 接入 SQLite + FTS5 建表 | `init_schema()` | 本地库可初始化 |
| D3 | 实现会话写入 / 查询 / 关键词检索 | CRUD + search API | 10+ 用例 |

**验收**：跨会话搜索可用；任意一次会话可完整回放。
