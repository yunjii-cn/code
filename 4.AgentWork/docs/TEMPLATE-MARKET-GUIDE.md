# 模板市场指南

> **目的**：帮助用户浏览、安装、提交、审核云集智能体工作台的社区模板。
> **生效日期**：2026-06-19
> **配套**：[IMPROVEMENT-PLAN.md](IMPROVEMENT-PLAN.md) § M4.2 D4

---

## 1. 概述

云集模板市场是一个社区驱动的行业模板分发平台，让任何创作者都可以把自己打造的行业模板分享给所有云集用户。

### 1.1 核心价值

| 角色 | 价值 |
|------|------|
| **客户（使用者）** | 一键安装现成行业模板，无需从零打造 |
| **创作者（作者）** | 上传模板赚分成（付费模板 70% 分成） |
| **平台** | 通过自动 + 人工双重审核保障质量 |

### 1.2 模板类型

- **官方模板**：由云集官方维护，免费提供（5 个核心行业）
- **社区模板**：由认证创作者上传，可免费或付费
- **私有模板**：公司内部使用，不进入公开市场（详见 [TEMPLATE-CUSTOMIZE-GUIDE.md](TEMPLATE-CUSTOMIZE-GUIDE.md)）

## 2. 浏览与安装

### 2.1 进入模板市场

点击侧边栏 **"模板市场"** 图标（Store 图标），进入市场首页。

### 2.2 浏览模板

- **搜索**：在搜索框输入模板名称、描述或标签
- **筛选**：
  - 行业：电商 / 教育 / 金融 / 医疗 / 全部
  - 定价：免费 / 付费 / 全部
- **排序**：
  - 最热门（下载量降序）
  - 评分最高（平均评分降序）
  - 最新发布（创建时间降序）

### 2.3 预览模板

点击模板卡片上的 **"预览"** 按钮，弹出详情窗口，查看：
- 模板名称、版本、作者
- 行业标签
- 员工数、下载量、评分
- 完整标签列表
- 定价信息

### 2.4 一键安装

点击 **"安装"** 按钮（或预览窗口中的 **"一键安装"**），模板会被下载到本地并注册到系统中。

安装后按钮变为 **"已安装"**（绿色），无法重复安装。

## 3. 提交模板（创作者）

### 3.1 进入提交向导

在模板市场首页右上角点击 **"提交我的模板"** 按钮，进入 4 步提交向导。

### 3.2 Step 1：上传清单

上传或粘贴 `manifest.yaml` 文件内容。

**清单格式示例**：

```yaml
id: ecommerce-fashion-custom
name: 电商-穿搭-定制版
version: 1.0.0
industry: ecommerce
sub_industry: fashion
description: 基于电商-穿搭模板定制的西装品牌专属模板
employees:
  - customer_service
  - fashion_advisor
  - tailor
files:
  employees:
    - employees/customer_service.yml
    - employees/fashion_advisor.yml
    - employees/tailor.yml
  knowledge:
    - knowledge/fabric_guide.md
    - knowledge/size_chart.md
  rules:
    - rules/rules.yaml
  speeches:
    - speeches/professional_advisor.yml
  evals:
    - evals/eval_suite.yaml
dependencies: []
```

**必填字段**：
- `id`：模板唯一标识（小写字母 + 数字 + 短横线）
- `name`：模板显示名称
- `version`：语义化版本号（x.y.z 格式）
- `industry`：行业分类
- `description`：模板描述

**可选字段**：
- `sub_industry`：子行业分类
- `dependencies`：依赖的其他模板

### 3.3 Step 2：自动校验

系统自动校验清单完整性：

**校验规则**：
- 必填字段不能为空
- 版本号格式必须为 `x.y.z`
- 至少 1 个员工
- `employees` 字段数与 `files.employees` 文件数必须一致
- 至少 1 个话术示例文件（建议 3+ 条）
- 至少 1 个评估用例文件（建议 5+ 条）
- 金融行业必须提供规则文件（合规红线）

**校验结果**：
- ✅ 通过：可进入下一步
- ❌ 未通过：显示错误列表，需修正后重新校验
- ⚠️ 警告：不阻塞流程，但建议优化

### 3.4 Step 3：定价与标签

#### 定价

| 选项 | 说明 |
|------|------|
| **免费** | 开放共享，积累声誉 |
| **付费** | 作者得 70% 分成，平台收 30% 维护费 |

付费模板需设置价格（元），最低 ¥1.00。

#### 标签

- 最多 8 个标签
- 每个标签便于用户搜索
- 建议标签：行业 / 子行业 / 特色（如"合规"、"AI 启蒙"）

#### LLM 自动评估

进入此步骤时，系统会自动调用 LLM-as-Judge 对模板进行三维度评估：

| 维度 | 满分 | 评估内容 |
|------|:---:|----------|
| 准确性 (Accuracy) | 100 | 员工定义完整性、知识库覆盖度 |
| 安全性 (Safety) | 100 | 合规检查、禁用词检查 |
| 实用性 (Usefulness) | 100 | 话术示例丰富度、评估用例覆盖度 |

**通过条件**：综合得分 ≥ 70 且安全性得分 ≥ 80。

### 3.5 Step 4：提交审核

确认信息无误后，点击 **"确认提交审核"**。

**审核流程**：
1. ✅ 自动 LLM 评估（已完成）
2. ⏳ 人工审核（1-3 个工作日）
3. 🚀 发布到市场

提交后会获得 **提交 ID**（如 `sub_xxx`），可用于查询审核状态。

---

## 4. 审核标准

### 4.1 自动评估维度

| 维度 | 权重 | 评分依据 |
|------|:---:|----------|
| 准确性 | 33% | 员工定义清晰、知识库完整、字段一致 |
| 安全性 | 33% | 合规红线、禁用词、风险话术 |
| 实用性 | 34% | 话术示例、评估用例、行业适配度 |

### 4.2 人工审核重点

- **内容合规**：无违法、色情、暴力内容
- **行业适配**：模板内容与所标行业匹配
- **质量达标**：话术自然、规则合理、知识库准确
- **用户体验**：员工职责清晰、流程闭环

### 4.3 审核结果

| 状态 | 说明 |
|------|------|
| **Approved** | 审核通过，发布到市场 |
| **Rejected** | 审核未通过，附拒绝原因 |
| **Delisted** | 已发布后被下架（违规 / 投诉） |

## 5. 评分与评论

### 5.1 评分

安装并使用模板后，用户可以打分（1-5 星）。

### 5.2 评分聚合

模板市场显示：
- 平均评分（1 位小数）
- 评分人数
- 星级分布（1-5 星各多少人）

### 5.3 评论

用户可附加文字评论，帮助其他用户决策。

## 6. 创作者分成

### 6.1 分成比例

| 项目 | 比例 |
|------|:---:|
| 作者 | 70% |
| 平台 | 30% |

### 6.2 结算周期

- 月度结算（每月 1 号结算上月收入）
- 最低提现金额：¥100
- 提现方式：支付宝 / 银行卡

### 6.3 收入示例

假设一个付费模板定价 ¥99，月销 100 份：
- 月总收入：¥9,900
- 作者分成：¥6,930（70%）
- 平台分成：¥2,970（30%）

## 7. 常见问题

### Q1：如何更新已发布的模板？

A：在创作者中心找到该模板，点击 **"发布新版本"**，上传新的 `manifest.yaml`（版本号必须高于当前版本），重新走审核流程。

### Q2：模板被拒绝怎么办？

A：查看拒绝原因，修正后重新提交。常见原因：
- 字段缺失或不一致
- 话术示例不足
- 评估用例覆盖不全
- 内容违规

### Q3：可以下架自己的模板吗？

A：可以。在创作者中心找到该模板，点击 **"下架"**。已安装的用户不受影响，但新用户无法安装。

### Q4：免费模板可以改为付费吗？

A：不可以。已发布的免费模板不能改为付费，但可以发布新的付费版本（v2.0.0）。

### Q5：模板支持哪些行业？

A：目前内置 5 个核心行业（电商穿搭 / 电商电子 / 教育早教 / 教育素质 / 金融证券），社区可上传任意行业模板。
