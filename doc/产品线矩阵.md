# 云集智能 — 产品线矩阵

> 版本：v2.0 | 日期：2026-06-17
> 文档定位：**商业 + 技术双轨入口**，4 个产品线定义 + 定价 + 差异 + 路线图

---

## 一、一句话定义

**云集智能** 是一家做 **AI 原生编程工作空间** 的公司。旗下 4 个产品线，分别对标**个人 / 专业人士 / 商业团队 / 企业研发** 四类用户，**1-3 代共享同一套 Platformkit 核心层**，**第 4 代独立技术栈（Tauri 2 + Rust）**。

---

## 二、产品线总览（4 代 4 目录，从根分离）

> **目录命名约定**：根目录 4 个数字前缀目录 = 4 个产品线 = 4 代技术栈
> **数字越小 = 代际越早 = 越稳定 = 越轻量**；数字越大 = 代际越新 = 越完整 = 越重磅

| # | 目录 | 产品名 | 形态 | 收费档 | 目标用户 | 状态 |
|---|------|--------|------|-------|---------|------|
| 1 | `1.PC/` | **云集桌面** | PyQt6 EXE | **免费版**（软件永久免费，云端模型可按算力收费） | 程序员 / 学生 / 隐私党 / 离线党 | ✅ 完整可跑（PyQt6 8000+ 行） |
| 2 | `2.WEB/` | **云集 Web** | FastAPI + pywebview + Vue 3 | **Pro 版** ¥9.9/月 | 自由职业 / 小团队 / 移动办公 | 🟡 半成品（慢慢补完） |
| 3 | `3.dev/` | **云集旗舰** | Web + 全部 Platformkit + 协作 | **Business 版** ¥99/月（或 ¥199/月打包企业定制） | 中型团队 / 企业 / 政府 | 🟢 全力开发（核心就位） |
| 4 | `4.AgentWork/` | **云集智能体工作台** | Tauri 2 + Rust + React | **Enterprise 版** ¥999/月/席位 | 企业研发团队 / 50+ 人企业 | 🆕 启动中（M0） |

> 备注：第 4 代是 2026 下半年新主力，独立技术栈（Tauri 2 + Rust），不依赖 1-3 代的 Platformkit。核心差异化是**五大支柱**：AI 团队协作引擎（多 Agent DAG + 异构模型）+ AST-Native 代码认知 + 编译期验证护栏 + TimeFlow 本地版本控制 + 全链路自动发布。

## 三、产品 1：云集桌面（Free）

### 3.1 一句话定位
**永久免费的本地 AI 编程工具**。双击即用，断网能用，Ollama 一键对接，**数据不离开你的电脑**。

### 3.2 商业模式
| 维度 | 内容 |
|------|------|
| **软件** | 永久免费（GitHub 开源，AGPL-3.0 或类似） |
| **算力** | 用户自备 Ollama / 本地模型 → **零成本**<br>云端模型（未来）→ 按 token 付费给模型厂商，我们不抽成 |
| **变现** | GitHub Sponsor / 捐赠 / **可选** Pro 版（未来） / 品牌曝光 |
| **不做** | 团队 / 多端同步 / 强制登录 / 遥测 / 任何"加好友"功能 |

### 3.3 核心卖点
- ✅ **永久免费**，无功能阉割
- ✅ **离线可用**，无网也能跑（Ollama 本地）
- ✅ **隐私第一**，代码、AI 对话、知识**100% 留本地**
- ✅ **Ollama 原生**，装好 Ollama 自动识别所有本地模型
- ✅ **零注册**，双击 EXE 即可使用
- ✅ **PyQt6 原生窗口**，比 Web 版响应更快、占资源更少

### 3.4 技术栈
| 层 | 技术 | 位置 |
|----|------|------|
| 桌面壳 | PyQt6 + QWebEngineView（自带 Chromium） | `desktop/app/main.py` |
| 后端 | Python 3.12 + FastAPI（内嵌） | `desktop/app/backend.py` |
| 前端 | Vue 3 + Vite + Vant（与产品 2 共享，但 PyQt6 渲染） | `desktop/app/web/` |
| IPC | QWebChannel（替代 Electron preload） | `desktop/app/main.py` |
| 打包 | PyInstaller --onedir | `desktop/build/build.py` |
| 输出 | `desktop/build_artifacts/云集桌面-v2026.06.10.1234/` |  |

## 四、产品 2：云集 Web（Pro）

### 4.1 一句话定位
**9.9 元/月**，**跨端跨平台**的 AI 编程工作空间。一个账户，**电脑、手机、平板**无缝切换。

### 4.2 商业模式
| 维度 | 内容 |
|------|------|
| **价格** | **¥9.9 / 月**（约 $1.4 / 月，对标 Cursor Pro $20/月，**主打性价比**） |
| **新人优惠** | 注册送 **¥30 体验金**（约 3 个月免费额度） |
| **额度** | 每月 **¥10 等值算力**（约 100 万 Claude Sonnet tokens / 50 万 GPT-4 tokens） |
| **超额** | 按 token 阶梯计费（**用多少付多少**，不强制订阅） |

| **变现** | 订阅 + 超额 token 抽成 + 模型厂商返佣 |

### 4.3 核心卖点
- ✅ **¥9.9 起**（行业最低价）
- ✅ **新人送额度**（零风险试用）
- ✅ **跨端同步**（电脑写一半，手机继续）
- ✅ **云端 AI 一键用**（不用配 Ollama）
- ✅ **本地也能用**（不想给数据走云，Ollama 模式）
- ✅ **PWA / Capacitor / 桌面壳**（手机就是 App）

## 五.4、产品 4：云集智能体工作台（Enterprise）

### 5.4.1 一句话定位
**999 元/月/席位**，**AI 研发团队协作平台**。多 Agent DAG 协作 + 异构模型绑定 + 本地版本控制 + 编译期验证 + 全链路发布。核心差异化是**五大支柱**。

### 5.4.2 商业模式
| 维度 | 内容 |
|------|------|
| **价格** | **¥999 / 月 / 席位**（对标 GitHub Enterprise $21/月，主打 AI 团队协作 + 本地隐私 + 零幻觉交付） |
| **团队档** | **¥299 / 月 / 席位**（5-50 人研发团队，Pro 功能） |
| **企业定制** | 单独议价（私有化部署 ¥50 万起 / 定制开发 ¥5 万 / 人月） |
| **变现** | 订阅 + 企业服务 + 私有化部署 |

### 5.4.3 核心卖点（五大差异化支柱）
- 🤝 **AI 团队协作引擎** ⭐王炸 — 多 Agent DAG 真并行 + 异构模型差异化绑定（Qwen3.7 推理/GLM5.2 代码/MiniMax3 视觉）+ Git 分支隔离 + 冲突自动解决
- 🧠 **AST-Native 代码认知** ⭐壁垒 — Tree-sitter + LanceDB 构建"类-方法-调用链"知识图谱，Token 消耗降低 70%，跨语言契约监听
- 🛡️ **编译期验证护栏** ⭐可信 — 五级验证管道（Lint/类型/编译/契约/调用链），破坏类型安全的代码直接拒绝合并，零幻觉交付
- 🔄 **TimeFlow 本地版本控制** — 不依赖 git 的本地优先 VCS，自动快照、自由回滚、分支管理
- 🚀 **全链路自动发布** — AI 整理正式版本 → 多目标构建 → 多平台分发（GitHub/Gitee/网盘/官网）→ 自动生成 Release Notes

### 5.4.4 完整能力
- 🔀 **Git 双模兼容** — 隐身模式（纯本地，代码永不上云）/ 同步模式（自动镜像 git）/ 发布模式（只推正式版本）
- 🧠 **AI 语义版本管理** — 自动 commit msg、版本号建议、changelog、语义搜索版本
- 🏷️ **AI 版本整理** — 自动区分 WIP/进度/候选/正式版本，识别"可发布版本"
- ⚙️ **工作流引擎** — 触发词/定时/事件驱动，YAML 定义自动化流程
- 🤖 **OpenHands Runtime** — AI 智能体替你写代码、提 PR、跑流水线
- 🔌 **MCP 标准协议** — 工具接入生态化
- 🦀 **Tauri 2 桌面** — Rust + WebView，体积小 10x
- 🏪 **Skills 市场** — 可复用任务模板
- 🐳 **Docker 沙箱** — 任务执行环境完全隔离

## 九、3 个产品线 vs 1 个产品（trae → trae solo）

**为什么不学 Trae → Solo 拆成独立产品？**

| 维度 | 云集方案 | Trae → Solo 方案 |
|------|----------|-----------------|
| 数量 | 1 品牌 + 3 产品线 | 1 品牌 + 1 子产品 |
| 关系 | **同平台 3 档**（共享 Platformkit） | **新范式**（AI 自主） |
| 范式变化 | ❌ 没变（还是 AI 协作） | ✅ 变了（从人主导 → AI 主导） |
| 用户迁移 | **平滑升档**（Free → Pro → Business） | **新用户群**（产品经理 / 非程序员） |
| 收入模型 | **订阅 + 算力 + 服务** | 暂未明确 |

**结论**：Trae Solo 是**范式跳跃**（值得独立产品）；云集 3 产品线是**用户分层**（不值得独立品牌）。
