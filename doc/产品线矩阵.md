# 云集智能 — 产品线矩阵

> 版本：v1.0 | 日期：2026-06-10
> 文档定位：**商业 + 技术双轨入口**，3 个产品线定义 + 定价 + 差异 + 路线图

---

## 一、一句话定义

**云集智能** 是一家做 **AI 原生编程工作空间** 的公司。旗下 3 个产品线，分别对标**个人 / 专业人士 / 商业团队** 三类用户，**共享同一套 Platformkit 核心层**，**前端和打包独立**。

---

## 二、产品线总览（3 代 3 目录，从根分离）

> **目录命名约定**：根目录 3 个数字前缀目录 = 3 个产品线 = 3 代技术栈
> **数字越小 = 代际越早 = 越稳定 = 越轻量**；数字越大 = 代际越新 = 越完整 = 越重磅

| # | 目录 | 产品名 | 形态 | 收费档 | 目标用户 | 状态 |
|---|------|--------|------|-------|---------|------|
| 1 | `1.PC/` | **云集桌面** | PyQt6 EXE | **免费版**（软件永久免费，云端模型可按算力收费） | 程序员 / 学生 / 隐私党 / 离线党 | ✅ 完整可跑（PyQt6 8000+ 行） |
| 2 | `2.WEB/` | **云集 Web** | FastAPI + pywebview + Vue 3 | **Pro 版** ¥9.9/月 | 自由职业 / 小团队 / 移动办公 | 🟡 半成品（慢慢补完） |
| 3 | `3.dev/` | **云集旗舰** | Web + 全部 Platformkit + 协作 | **Business 版** ¥99/月（或 ¥199/月打包企业定制） | 中型团队 / 企业 / 政府 | 🟢 全力开发（核心就位） |

> 备注：未来**可能**给"云集桌面"加收费档（Pro 版），但**当前阶段只做免费版**。云端模型按算力收费由**模型路由**（`3.dev/platformkit/shared/model_router.py`）实现。

## 三、产品 1：云集桌面（Free）

### 3.1 一句话定位
**永久免费的本地 AI 编程工具**。双击即用，断网能用，Ollama 一键对接，**数据不离开你的电脑**。

### 3.2 商业模式
| 维度 | 内容 |
|------|------|
| **软件** | 永久免费（GitHub 开源，AGPL-3.0 或类似） |
| **算力** | 用户自备 Ollama / 本地模型 → **零成本**<br>云端模型（未来）→ 按 token 付费给模型厂商，我们不抽成 |
| **变现** | GitHub Sponsor / 捐赠 / **可选** Pro 版（未来） / 品牌曝光 |
| **不做** | 团队 / 多端同步 / 强制登录 / 遥测 / 任何"加好友"功能 |

### 3.3 核心卖点
- ✅ **永久免费**，无功能阉割
- ✅ **离线可用**，无网也能跑（Ollama 本地）
- ✅ **隐私第一**，代码、AI 对话、知识**100% 留本地**
- ✅ **Ollama 原生**，装好 Ollama 自动识别所有本地模型
- ✅ **零注册**，双击 EXE 即可使用
- ✅ **PyQt6 原生窗口**，比 Web 版响应更快、占资源更少

### 3.4 技术栈
| 层 | 技术 | 位置 |
|----|------|------|
| 桌面壳 | PyQt6 + QWebEngineView（自带 Chromium） | `desktop/app/main.py` |
| 后端 | Python 3.12 + FastAPI（内嵌） | `desktop/app/backend.py` |
| 前端 | Vue 3 + Vite + Vant（与产品 2 共享，但 PyQt6 渲染） | `desktop/app/web/` |
| IPC | QWebChannel（替代 Electron preload） | `desktop/app/main.py` |
| 打包 | PyInstaller --onedir | `desktop/build/build.py` |
| 输出 | `desktop/build_artifacts/云集桌面-v2026.06.10.1234/` |  |

## 九、3 个产品线 vs 1 个产品（trae → trae solo）

**为什么不学 Trae → Solo 拆成独立产品？**

| 维度 | 云集方案 | Trae → Solo 方案 |
|------|----------|-----------------|
| 数量 | 1 品牌 + 3 产品线 | 1 品牌 + 1 子产品 |
| 关系 | **同平台 3 档**（共享 Platformkit） | **新范式**（AI 自主） |
| 范式变化 | ❌ 没变（还是 AI 协作） | ✅ 变了（从人主导 → AI 主导） |
| 用户迁移 | **平滑升档**（Free → Pro → Business） | **新用户群**（产品经理 / 非程序员） |
| 收入模型 | **订阅 + 算力 + 服务** | 暂未明确 |

**结论**：Trae Solo 是**范式跳跃**（值得独立产品）；云集 3 产品线是**用户分层**（不值得独立品牌）。
