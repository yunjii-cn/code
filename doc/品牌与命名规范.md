# 云集智能品牌与命名规范

> 状态：现行草案  
> 范围：产品线命名 / 站点命名 / AgentWork 品牌色与 Logo 方向  
> 最近更新：2026-06-24

## 1. 总体原则

云集智能的命名分三层：

- **目录名**：面向工程协作，优先稳定、短、可检索。
- **产品名**：面向用户表达，优先清晰、可信、可销售。
- **品牌名**：面向长期资产，优先识别度、统一性和可扩展性。

目录名不必完全等于对外产品名。目录是工程标识，产品名是市场表达，两者通过本文档建立映射。

## 2. 产品线命名决策

| 代 | 当前目录 | 规范产品名 | 英文名 | 对外口径 | 目录决策 |
|---|---|---|---|---|---|
| 1 | `1.PC/` | 云集 PC 版 | Yunji PC | 也可在说明文案中称“云集桌面版” | **保留 `1.PC/`** |
| 2 | `2.WEB/` | 云集 Web 版 | Yunji Web | 低价多端轻量版 | 保留 `2.WEB/`，后续如统一大小写可迁移到 `2.Web/` |
| 3 | `3.dev/` | 云集团队版 | Yunji Team | Business 档团队协作版 | 当前保留 `3.dev/`，迁移目标为 `3.Team/` |
| 4 | `4.AgentWork/` | AgentWork / 云集智能体工作台 | AgentWork | Enterprise 档 AI 员工与智能体工作台 | 保留 `4.AgentWork/` |

### 2.1 为什么保留 `1.PC/`

`PC 版`在中文软件市场是成熟表达，短、清楚、用户无理解成本。`Desktop` 更国际化，但作为目录更长，也不比 `PC` 更准确；当前产品是 PyQt6/Windows 桌面形态，`1.PC/` 的工程识别度更高。

不建议把第 1 代命名为“开源版”。开源是许可证和分发策略，不是产品形态；一旦把产品叫“开源版”，后续免费版、社区版、商业版、云端算力等表达都会被它限制。

### 2.2 为什么第 3 代用 Team 而不是 biz/dev

`dev` 是开发阶段或技术方向，不适合作为长期产品名。`biz` 过泛，容易像内部业务系统，也不能清楚表达第 3 代与第 4 代的边界。

第 3 代建议定位为 **云集团队版 / Yunji Team**：它承接 Business 档、团队协作、多端平台、知识协作、安全审计等能力。第 4 代 AgentWork 则专注 Enterprise 档的 AI 员工、行业模板、自进化工作台和更强的 Agent Runtime。

物理目录迁移建议单独执行：先让站点和文档全部按 `云集团队版 / Yunji Team` 写，再安排一次 `3.dev/` -> `3.Team/` 的集中迁移，避免边开发站点边改工程路径。

### 2.3 AgentWork 与 AW 的使用边界

- 对外品牌、官网标题、销售材料、合同和商标：使用 **AgentWork**。
- 中文解释：使用 **云集智能体工作台**。
- 图标、CLI、技术标识、短标签：可以使用 **AW** 或小写 `aw`。
- 不建议把“AW”作为主品牌名。AW 适合做识别符和图标，不适合作为主要市场名称；它也容易和 AWS 在视觉上接近。

## 3. 双站点命名

| 域名 | 站点名 | 职责 |
|---|---|---|
| `work.yunjii.cn` | 云集工作台 | 产品矩阵门户、统一身份入口、生态路由 |
| `aw.yunjii.cn` | AgentWork 官网 | AgentWork 产品叙事、行业方案、企业转化 |

`work.yunjii.cn` 讲清“云集有哪些产品，用户该选哪个”。`aw.yunjii.cn` 只重点讲 AgentWork，不把前 3 代放成同等主角。

## 4. AgentWork Logo 方向

### 4.1 结论

AgentWork 图标建议采用：

- **外形**：圆角方形 app icon，不用圆形、六边形、菱形或复杂多边形。
- **底色**：使用 AW 专属蓝 `#1E6CF0`，不再使用云集母品牌红作为 AW 主底色。
- **图形**：白色几何 AW monogram，不直接放普通字母。
- **母品牌基因**：继承官网 Logo 的“三柱 / 云集条形”记忆点，但通过蓝色体系和 AW monogram 与母品牌红云图标区分。
- **首选方案**：Agent Grid。用三根竖柱和一条斜向连接构成抽象 A/W，表达 Agent、Workflow、协作网络。

### 4.2 外形取舍

| 外形 | 判断 |
|---|---|
| 圆形 | 适合作为系列徽章，例如 LH；但用于 AW 会偏社交头像或活动章，不够产品化 |
| 六边形 | 偏区块链、工业、开发者工具，容易显得硬和冷 |
| 菱形 | 识别强，但小尺寸和中文品牌体系不够稳定 |
| 多边形 | 设计风险高，容易过时 |
| 圆角方形 | 最适合作为 app、favicon、桌面图标、官网产品图标，和云集主品牌图标体系一致 |

### 4.3 三个可出图方向

1. **Agent Grid**  
   三根竖柱继承云集主 Logo 的结构，中间用斜线形成 A 的上升势能，整体读成 AW。最适合作为主方案。

2. **AW Fold**  
   用一条连续白色折带构成 A 峰和 W 谷，强调工作流、自进化和任务编排。更动感，但要控制复杂度。

3. **Cloud Core AW**  
   保留极简云弧，再把内部三柱重构成 AW。品牌继承最强，但风险是和母品牌图标太像。

## 5. 色彩体系

### 5.1 品牌色决策

云集母品牌与 AW 产品品牌分开：

- **云集母品牌**：红色，用于公司 Logo、官网主品牌、集团级标识。
- **AgentWork / AW**：蓝色 `#1E6CF0`，用于 AW Logo、AW 官网、CTA、关键交互和 Agent 激活态。

`#1E6CF0` 是 AW 的实际品牌主色。之前文档中出现的 `#3B82F6`、蓝紫渐变或科技蓝方案，只作为历史设计假设，不再作为现行主色。

### 5.2 色彩令牌

| 角色 | 色值 | 用途 |
|---|---|---|
| AW 主色 | `#1E6CF0` | AW Logo 底色、主 CTA、核心高亮、DAG 节点、激活态 |
| AW 深蓝 | `#1553C7` | hover、pressed、深色背景上的强调边框 |
| AW 浅蓝 | `#5B9BFF` | 微光、focus ring、图表辅助线 |
| AW 微光 | `rgba(30, 108, 240, 0.28)` | 按钮 hover、运行态、Agent 活跃状态 |
| 云集主红 | `#E61912` | 公司/母品牌 Logo，不作为 AW 主色 |
| 云集深红 | `#B81410` | 母品牌深色场景 |
| 背景黑 | `#0B0D12` | 双站暗色基底 |
| 表面深灰 | `#121620` | 卡片、导航、面板 |
| 边框 | `rgba(255, 255, 255, 0.10)` | 暗色 UI 分隔 |
| 主文字 | `#F8FAFC` | 标题和主要正文 |
| 次文字 | `#A1A8B3` | 说明、辅助信息 |
| 白色图形 | `#FFFFFF` | AW 图标内部图形 |

### 5.3 双站点用色

| 站点 | 用色策略 |
|---|---|
| `work.yunjii.cn` | 使用同一套暗色基底和 `#1E6CF0` 主色，但色彩出现频率低，主要用于 CTA、当前选中、产品矩阵中的 AW 入口 |
| `aw.yunjii.cn` | 使用同一主色 `#1E6CF0`，但色彩权重更高，可用于 Hero、关键节点、交互动效和产品能力图 |

两个站点不再拆成两套完全不同的配色。统一主色能让用户从 `work.yunjii.cn` 跳到 `aw.yunjii.cn` 时保持同一产品体系认知；AW 的旗舰感通过布局、动效、图形密度和色彩使用强度体现，而不是另起一套颜色。

### 5.4 Logo 参数

| 项 | 建议 |
|---|---|
| 图标底色 | `#1E6CF0` |
| 图形颜色 | `#FFFFFF` |
| 暗底反色版 | `#1E6CF0` 图形 + `#0B0D12` 背景 |
| 圆角比例 | 宽高的 22% - 26% |
| 图形留白 | 四周 18% - 20% |
| 主字体 | 中文：HarmonyOS Sans SC / Noto Sans SC；英文：Inter |

主 Logo 先做纯色矢量，不把渐变作为主版本。等纯色版本在 16px favicon、32px app icon、128px 桌面图标和官网首屏都成立后，再做深色版、反白版和动效版。

## 7. 前端色彩变量

双站点和 AgentWork Web UI 优先使用语义变量，不在组件里直接写死色值。

```css
:root {
  --yj-brand-red: #e61912;
  --yj-brand-red-deep: #b81410;

  --aw-primary: #1e6cf0;
  --aw-primary-hover: #1553c7;
  --aw-primary-soft: #5b9bff;
  --aw-primary-glow: rgba(30, 108, 240, 0.28);

  --aw-bg: #0b0d12;
  --aw-surface: #121620;
  --aw-surface-elevated: #171c28;
  --aw-border: rgba(255, 255, 255, 0.10);

  --aw-text: #f8fafc;
  --aw-text-muted: #a1a8b3;
  --aw-text-faint: #697282;
}
```

Tailwind 主题建议：

```js
export default {
  theme: {
    extend: {
      colors: {
        yj: {
          red: "#E61912",
          "red-deep": "#B81410",
        },
        aw: {
          primary: "#1E6CF0",
          hover: "#1553C7",
          soft: "#5B9BFF",
          bg: "#0B0D12",
          surface: "#121620",
          elevated: "#171C28",
          text: "#F8FAFC",
          muted: "#A1A8B3",
        },
      },
      boxShadow: {
        "aw-glow": "0 0 24px rgba(30, 108, 240, 0.28)",
        "aw-glow-strong": "0 0 36px rgba(30, 108, 240, 0.40)",
      },
    },
  },
};
```
