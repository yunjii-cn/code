## v2.0 发布公告：技能市场 + 智能模型路由 + 跨端体验全面升级

### 一句话总结

**云集智能编程工作站 v2.0 正式发布 — 技能市场开箱即用，智能路由省 Token 又高效，手机/平板/桌面全端流畅体验。**

### 三大核心更新

#### 1. 技能市场 — 12 个官方技能，一键安装

不再从零开始。v2.0 内置 12 个官方技能包，覆盖 React、Python、API 设计、代码审查等高频场景：

- **全局安装**：所有项目共享，一次安装到处可用
- **项目安装**：仅当前项目生效，团队协作不冲突
- **评分系统**：社区驱动的质量筛选
- **技能导出**：一键导出 `.zip`，分享给团队

```
技能市场已上线 12 个官方技能：
🔧 React 开发专家    🔧 Python 开发专家    🔧 API 设计专家
🔧 代码审查专家      🔧 测试工程师         🔧 DevOps 专家
🔧 数据库设计专家    🔧 安全审计专家       🔧 性能优化专家
🔧 文档工程师        🔧 架构设计专家       🔧 Git 工作流专家
```

#### 2. 智能模型路由 — 简单任务走本地，复杂任务上云端

告别"一刀切"的模型选择。v2.0 引入 4 维复杂度评分算法：

| 维度 | 权重 | 说明 |
|------|------|------|
| 长度 | 25% | Token 数量估算 |
| 关键词 | 30% | "重构/架构/安全"等重量级词汇 |
| 结构 | 25% | 代码块/多文件/层级深度 |
| 历史 | 20% | 同类任务的历史路由偏好 |

**3 级自动路由**：
- **简单**（< 0.3）：自动走本地 Ollama，零成本
- **中等**（0.3-0.7）：走性价比模型（如 DeepSeek）
- **复杂**（> 0.7）：走最强模型（如 Claude），确保质量

**自动降级**：云端挂了？自动切本地，不中断工作。

#### 3. 跨端体验全面打磨

```
📱 手机端          📋 平板端          🖥️ 桌面端
─────────────────────────────────────────────
触屏手势           分栏布局           完整功能
下拉刷新           侧边栏收缩         键盘快捷键
44px 点击区域      横竖屏适配          桌面通知
骨架屏加载         触屏+鼠标双模       hover 交互
```

- **平板专属**：768-1023px 断点，侧边栏自动收缩为图标模式
- **触屏手势**：4 方向滑动 + 下拉刷新（带阻尼回弹）
- **骨架屏加载**：路由懒加载不再白屏，流畅的 shimmer 动画
- **ErrorBoundary**：组件崩溃不白屏，显示错误信息 + 一键重试
- **无障碍**：`prefers-reduced-motion` 自动关闭动效，尊重用户偏好
- **微交互**：按钮按压反馈，触屏 44px 最小点击区域

## 二、核心卖点（7 大独有能力）

### 卖点 1：主动感知 — AI 不等你问

> 别人：人问 AI 答
> 我们：AI 主动发现问题、主动建议、主动提醒

**场景**：
- 代码有安全漏洞？AI 主动提醒你修复
- 依赖包过时了？AI 主动建议升级
- 上次没写完的功能？AI 主动提醒继续
- 测试失败了？AI 主动分析原因并建议修复

### 卖点 2：越用越聪明 — 知识永不丢失

> 别人：关掉就忘，每次从零开始
> 我们：纠正永不再犯，模式自动提炼，偏好自动应用

**场景**：
- 你纠正过一次"用 const 不用 var"，AI 永远记住
- 你连续3次手动测试→提交→部署，AI 自动生成"发布流程"技能
- 你说过"这个项目用 PostgreSQL"，AI 所有 SQL 都用 PG 语法
- 换了电脑、换了模型，项目知识依然完整

### 卖点 3：AI 团队协作 — 一个人顶一个团队

> 别人：一个 AI 串行干活
> 我们：多个 AI 角色并行协作，边界治理不冲突

**场景**：
- 架构师设计 → 开发工程师编码 → 测试工程师验证 → 文档工程师出文档
- 前端后端同时开工，互不干扰
- 关键步骤人工审批，安全可控

### 卖点 4：代码变更全追踪 — AI 改了什么一目了然

> 别人：AI 改了一堆文件，你不知道改了啥
> 我们：红绿对比 DiffView，每步可查，随时回退

**场景**：
- AI 写完代码，点击查看变更，红绿对比一目了然
- 不满意？一键回退
- 每个对话步骤都能查看对应的代码变更

### 卖点 5：手机远程编码 — 躺床上也能写代码

> 别人：只能坐在电脑前
> 我们：手机远程连接电脑，随时随地编程

**场景**：
- 躺床上让 AI 写代码，手机上审查 DiffView
- 通勤路上收到安全漏洞通知，一键修复
- 开会时远程查看项目状态
- 电脑做后端，手机做前端，零额外成本

### 卖点 6：本地模型支持 — 离线也能用

> 别人：必须联网，数据上云
> 我们：Ollama 本地模型，离线编码，数据不出本机

**场景**：
- 无网络时仍可用本地模型编码
- 敏感代码只走本地模型，隐私安全
- 简单任务用本地模型省 Token，复杂任务用云端

### 卖点 7：体积缩小 5 倍 — 从 200MB 到 38MB

> 别人：内嵌 Chromium，200MB+
> 我们：复用系统 WebView2，38MB
