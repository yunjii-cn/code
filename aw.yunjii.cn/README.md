# aw.yunjii.cn

> 状态：待开发  
> 范围：AgentWork 旗舰产品站 / 企业转化  
> 最近更新：2026-06-24

`aw.yunjii.cn` 是 AgentWork 专属产品站，负责讲清第 4 代云集智能体工作台的价值。

## 定位

- 主推 AI 员工、AI 团队、行业模板、自进化工作台。
- 承接预约演示、早期试用和企业咨询。
- 展示 AgentWork 的行业方案、能力支柱、路线图和验证机制。
- 登录和试用入口接入 `work.yunjii.cn` 或 UM 统一身份。

## 首版页面

1. 首页：AgentWork 产品叙事和核心 CTA。
2. 行业模板页：电商、教育、金融，后续扩展法律、财务、HR、医疗。
3. 能力页：AI 团队、AI 员工训练、互动双引擎、本地优先 + 云端协同。
4. 路线图页：M0 到 Beta/GA。
5. 预约演示页：先静态表单占位，后续接轻量 API。

## 开发约束

- 可在当前仓库孵化，但构建、部署和内容目录从第一天保持可拆分。
- 不重复建设独立登录和用户数据库。
- 不把前 3 代产品作为同等重点展示；需要矩阵说明时跳转 `work.yunjii.cn`。
- 产品能力依据 [../4.AgentWork/docs/README.md](../4.AgentWork/docs/README.md)，品牌方向依据 [../4.AgentWork/docs/BRAND.md](../4.AgentWork/docs/BRAND.md)，站点计划依据 [../doc/双站点开发计划.md](../doc/双站点开发计划.md)。
