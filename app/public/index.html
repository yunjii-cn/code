核心特性

🖥️ 双端体验

同时提供基于 React + Ink 的沉浸式终端 TUI 和基于 Vue 3 的现代化 Electron 桌面界面。

🤖 全能 Agent

内置 Bash、文件编辑、代码搜索等核心工具，支持多步迭代与复杂任务自动化。

⚡ 高度可定制

通过 .env 轻松配置 API 端点，支持 MiniMax、OpenRouter 等第三方服务，灵活适配。

🛠️ 稳定性修复

解决了原始源码在本地环境下的启动卡死、按键失效等问题，确保开发体验流畅。

快速开始

git clone https://github.com/your-repo/claude-code-tudou.git
cd claude-code-tudou
npm install
cp .env.example .env
# 编辑 .env 填入你的 API Key
./bin/claude-code-tudou
