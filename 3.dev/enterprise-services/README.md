## 服务流程

```
1. 客户咨询
   ↓
2. 需求评估（免费 1 小时）
   ↓
3. 报价（48 小时内）
   ↓
4. 签订服务合同 + 预付 50%
   ↓
5. 启动服务（指派客户经理）
   ↓
6. 交付 + 验收 + 尾款
   ↓
7. 持续支持（可选续约）
```

## 不做什么

- ❌ 不**单独卖产品代码**（产品开源在 GitHub）
- ❌ 不**强制搭售**（客户可单独买授权 / 部署 / 定制 / 支持 / 培训任一项）
- ❌ 不**承诺 SLA < 99.9%**（私有化部署的可用性取决于客户基础设施）
