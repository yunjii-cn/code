# 稳定版 EXE 目录

此目录用于存放稳定版 EXE。

## ⚠️ 注意：--onedir 模式的限制

当前项目使用 `--onedir` 模式打包（QtWebEngine 不支持 `--onefile`），EXE 文件需要配合 `_internal/` 目录才能运行。

因此，稳定版 EXE **不通过 Git 仓库分发**，而是通过以下方式：

1. **直接提供给用户**：将 `build/版本名/` 整个目录打包为压缩包分发
2. **未来方案**：如果实现 `--onefile` 模式（去掉 WebEngine 改用其他方案），EXE 可以直接放在此目录推送
