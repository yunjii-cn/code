## 〇、战略决策：产品先行，鸡生蛋

### 核心原则

**先做好"云集智能编程工作站"这一个产品，用它来生其他产品的蛋。**

1. **编程工作站先行** — 作为基石产品，全力打磨到可用、好用
2. **架构兼顾蓝图** — 核心层与业务层分离，接口标准化，为未来扩展留好接口
3. **用工作站开发其他产品** — 鸡生蛋，工作站本身就是最好的 dogfooding
4. **从产品中提炼平台** — 当多个产品共用同一套核心能力时，平台自然形成
5. **模块组建平台** — 成熟的产品模块化后，组合成平台，形成生态交互

### 为什么不先搭平台

| 先搭平台的风险 | 产品先行的优势 |
|---------------|--------------|
| 过度设计 — 没有真实场景验证的抽象往往是错的 | 需求驱动 — 从真实需求中提炼的抽象才准确 |
| 见效慢 — 数月无可用产出 | 见效快 — 编程工作站立即可用可变现 |
| 投入大 — 平台开发成本高且无收入 | 自造血 — 产品收入支撑后续开发 |
| 动力不足 — 看不到用户反馈容易偏离方向 | 正循环 — 用户反馈驱动产品迭代 |

### 编程工作站的战略地位

编程工作站不只是第一个产品，它是整个生态的**基石**：

```
云集智能编程工作站（鸡）
    │
    ├── 验证 AI 引擎 → 未来所有产品共用
    ├── 验证主动感知 → 未来所有产品主动化
    ├── 验证自进化知识 → 未来所有产品越用越聪明
    ├── 验证模块架构 → 未来产品即模块
    ├── 验证跨平台壳 → 未来所有产品跨平台
    │
    ├── 用工作站开发创意工坊 → 创意工坊是蛋1
    ├── 用工作站开发 AI 世界 → AI 世界是蛋2
    ├── 用工作站开发工具箱 → 工具箱是蛋3
    │
    └── 鸡和蛋共用核心 → 核心即平台 → 生态形成
```

### 名字的自然演化

```
Phase 1: 云集智能编程工作站 ← 现在就是这个名字
  聚焦编程，鸡生蛋

Phase 2: 云集智能工作站 ← 去掉"编程"
  编程 + 创意 + 办公，工作站自然扩展

Phase 3: 云集 ← 品牌即品类
  就像"微信"不需要叫"微信通讯"，"云集"本身就是那个空间
```

### 开发节奏

```
Phase 1: 云集智能编程工作站（基石产品，全力打磨）
  ├── 核心：AI 引擎 + 主动感知 + 自进化知识 + 工程化持久化
  ├── 独行模式：Plan + Tool + DiffView + Skills
  ├── 团队模式：多Agent + 任务看板 + 边界治理 + 审批
  └── 交付：可独立使用的 AI 编程工作站

Phase 2: 用工作站开发第二个产品（创意工坊 or AI 世界）
  ├── 从工作站中提取可复用核心层
  ├── 新产品复用核心层 + 开发业务层
  └── 交付：第二个独立产品

Phase 3: 第三个产品 + 核心层正式升级为"平台"
  ├── 三个产品共用核心层 → 核心层即平台
  ├── 产品模块化 → 可插拔组合
  └── 交付：云集智能平台 v1.0

Phase 4: 插件生态 + 市场化
  ├── 开放插件 SDK
  ├── 上线插件市场
  └── 交付：开放生态
```

## 一、产品愿景

云集不再是一个单一的编程工具，而是一个 **AI 驱动的超级平台** — 编程、办公、创作、社交、娱乐，一切皆可对话。

核心理念：

- **模块化架构** — 每个功能域是一个独立模块，可插拔、可组合、可独立升级
- **插件化生态** — 第三方开发者可以创建和发布插件，无限扩展平台能力
- **AI 原生** — 每个模块都以 AI 为核心交互方式，自然语言即操作界面
- **多角色智能体** — AI 不只是助手，可以是员工、伙伴、对手、玩家
- **跨平台统一** — 桌面端 + 手机端 + Web 端，一套代码多端运行

## 五、模块化 + 插件化架构

### 5.1 为什么必须模块化

你的直觉完全正确 — **无限拓展的唯一解就是模块化 + 插件化**。

原因：
1. **功能域差异巨大** — 编程和游戏几乎没有任何代码重叠，硬塞在一起只会互相拖累
2. **独立迭代** — 每个模块可以独立开发、测试、发布，不影响其他模块
3. **按需加载** — 用户只安装需要的模块，保持核心轻量
4. **第三方生态** — 插件化让社区可以贡献模块，平台能力无限扩展
5. **商业模式** — 基础模块免费，高级模块付费，灵活定价

```python
        """模块卸载时的清理逻辑"""

    @abstractmethod
    def get_settings_schema(self) -> dict:
        """模块的设置项 JSON Schema"""

    @abstractmethod
    def get_ai_capabilities(self) -> list[AICapability]:
```

### 5.5 前端模块加载

```typescript
// 前端模块加载器
interface ModuleManifest {
  id: string
  name: string
  icon: string
  routes: ModuleRoute[]
  components: ModuleComponent[]
  settings: SettingSchema[]
}

class ModuleLoader {
  private modules: Map<string, ModuleManifest> = new Map()

  async loadModule(moduleId: string) {
    const manifest = await fetch(`/api/modules/${moduleId}/manifest`).then(r => r.json())
    this.modules.set(moduleId, manifest)

    // 动态注册路由
    manifest.routes.forEach(route => {
      router.addRoute({
        path: route.path,
        component: () => import(`../modules/${moduleId}/${route.component}`)
      })
    })

    // 动态注册导航项
    manifest.components.forEach(comp => {
      navigationRegistry.register({
        moduleId,
        icon: manifest.icon,
        label: manifest.name,
        path: comp.path
      })
    })
  }

  async unloadModule(moduleId: string) {
    const manifest = this.modules.get(moduleId)
    if (!manifest) return

    // 移除路由
    manifest.routes.forEach(route => router.removeRoute(route.name))
    // 移除导航
    navigationRegistry.unregister(moduleId)
    this.modules.delete(moduleId)
  }
}
```

### 8.2 多模型并行调度

```python
class MultiModelScheduler:
    async def parallel_chat(
        self,
        prompt: str,
        models: list[str],
        on_chunk: Callable[[str, str], None],  # (model_id, chunk)
    ):
        tasks = []
        for model_id in models:
            task = self._chat_single(model_id, prompt, on_chunk)
            tasks.append(task)
        await asyncio.gather(*tasks)

    async def debate_round(
        self,
        topic: str,
        participants: list[Debater],
        rounds: int = 3,
    ):
        for round_num in range(rounds):
            for debater in participants:
                context = self._build_debate_context(round_num, debater)
                response = await self._chat(debater.model, context)
                yield DebateTurn(
                    round=round_num,
                    debater=debater,
                    content=response
                )

    async def consensus(
        self,
        question: str,
        models: list[str],
        max_rounds: int = 5,
    ):
        answers = {}
        for model_id in models:
            answers[model_id] = await self._chat(model_id, question)

        for round_num in range(max_rounds):
            differences = self._find_differences(answers)
            if not differences:
                return ConsensusResult(agreed=True, answer=answers[models[0]])

            for model_id in models:
                review = self._build_review_prompt(model_id, answers, differences)
                answers[model_id] = await self._chat(model_id, review)

        return ConsensusResult(agreed=False, answers=answers, differences=differences)
```
