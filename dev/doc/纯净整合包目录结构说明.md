# 纯净整合包目录结构说明

## 📋 概述

从 v2026.05.13 开始，我们采用了**三目录纯净整合包结构**：
- **app/** - 应用程序代码（只读，纯净可发布）
- **data/** - 用户数据（需要备份）
- **temp/** - 临时文件（无需备份，可随时删除）

这样设计让app保持纯净可以直接分发，用户只需备份data目录，temp目录可以随时清理。

### 三目录职责

| 目录 | 性质 | Git管理 | 备份 | 说明 |
|------|------|---------|------|------|
| **app/** | 只读 | ✅ 是 | ❌ 不需要 | 应用程序代码，纯净可发布 |
| **data/** | 可写 | ❌ 否 | ✅ **必须** | 用户重要数据+运行环境，升级时保留 |
| **temp/** | 可写 | ❌ 否 | ❌ 不需要 | 临时文件，可随时删除 |

### 数据分级（data目录内部）

| 数据类型 | 位置 | 访问权限 | 说明 |
|---------|------|---------|------|
| **公共数据** | `data/public/` | 所有用户共享 | 模型、模板、插件、API配置 |
| **用户私密数据** | `data/users/{user_id}/` | 仅当前用户 | 项目、会话、API密钥、.env |

**注意：** `data/venvs/` 是Python虚拟环境，包含API服务依赖库，体积较大。环境是用户的重要资产，升级时应保留，避免重复安装。用户如需要节省空间，可自行删除并重新安装。

### 核心原则

- ✅ **app/ 是纯净的** - 只包含代码和资源，可以直接打包作为宣传发布版本
- ✅ **data/ 包含所有用户重要数据** - 项目、会话、API密钥等，**需要备份**
- ✅ **data/public/ 是共享的** - 模型、模板、插件等公共资产
- ✅ **data/users/ 是隔离的** - 每个用户独立空间，保护私密数据
- ✅ **temp/ 包含所有临时文件** - logs、cache、debug等，**无需备份，可随时删除**
- ✅ **方便升级** - 替换app/和EXE，保留data/，删除temp/
- ✅ **便于分发** - app目录不含任何用户数据，可直接用于演示
- ✅ **多用户就绪** - 用户数据隔离，未来可直接接入登录系统

### ProjectManager 多用户支持

```python
class ProjectManager:
    DEFAULT_USER_ID = "default"
    
    def __init__(self, app_dir: str, base_dir: str, data_dir: str = None, user_id: str = None):
        self.data_root = data_dir if data_dir else os.path.join(base_dir, "data")
        self.user_id = user_id or self.DEFAULT_USER_ID
        
        # 公共数据目录
        self.public_dir = os.path.join(self.data_root, "public")
        
        # 用户数据目录
        self.data_dir = os.path.join(self.data_root, "users", self.user_id)
        self.projects_dir = os.path.join(self.data_dir, "projects")
        self.sessions_dir = os.path.join(self.data_dir, "sessions")
```

### 用户切换API

```python
# BackendBridge 中的用户管理API

@pyqtSlot(result=str)
def getCurrentUser(self):
    """获取当前用户信息"""
    return json.dumps({
        "id": main.current_user_id,
        "name": main.current_user_id,
        "is_default": main.current_user_id == "default"
    })

@pyqtSlot(result=str)
def listUsers(self):
    """列出所有用户目录"""
    users = []
    users_dir = os.path.join(main.data_dir, "users")
    for uid in os.listdir(users_dir):
        if os.path.isdir(os.path.join(users_dir, uid)):
            users.append({"id": uid, "name": uid})
    return json.dumps(users)

@pyqtSlot(str, result=bool)
def switchUser(self, user_id: str):
    """切换用户 - 重新初始化所有用户相关组件"""
    # 1. 保存当前用户状态
    main.project_mgr._save_registry()
    
    # 2. 切换用户ID
    main.current_user_id = user_id or "default"
    main.user_dir = os.path.join(main.data_dir, "users", main.current_user_id)
    
    # 3. 重新初始化 ProjectManager
    main.project_mgr = ProjectManager(
        main.app_dir, main.exe_dir, 
        data_dir=main.data_dir, user_id=main.current_user_id
    )
    
    # 4. 重新加载用户环境配置
    main.env_manager = EnvFileManager(os.path.join(main.user_dir, ".env"))
    
    # 5. 更新当前项目状态
    main.active_project_id = None
    active_proj = main.project_mgr.get_active_project()
    if active_proj:
        main.active_project_id = active_proj["id"]
    
    return True
```

## ❓ 常见问题

### Q1: 为什么logs放在temp下而不是data下？

A: 因为日志是运行时产生的临时数据，不是用户的重要文件。放在temp下可以让用户清楚知道这些文件不需要备份，可以随时清理。

### Q2: temp目录可以删除吗？

A: **可以！** temp目录中的所有文件都可以安全删除。程序会在需要时自动重新创建相应的子目录。

### Q3: _internal目录是什么？

A: `_internal/` 是PyInstaller打包后生成的运行时目录，包含Python解释器、PyQt6等框架的DLL文件。它是EXE运行所必需的，不应删除。在Windows上该目录默认设为隐藏属性。

### Q4: data和temp的区别是什么？

A: 
- **data/** - 用户重要数据（配置、项目、会话、API数据等），**需要备份**
- **temp/** - 临时文件（日志、缓存、调试信息等），**无需备份**

### Q5: 开发环境下如何使用新结构？

A: 在开发环境下（非frozen），程序使用以下路径：
- `dev/app/` 作为app目录
- `dev/data/` 作为data目录
- `dev/temp/` 作为temp目录

### Q6: 为什么数据要分public和users？

A: 
- **public/** - 公共数据（模型、模板、插件等），所有用户共享，节省磁盘空间
- **users/** - 用户私密数据（项目、会话、API密钥等），每个用户独立，保护隐私

### Q7: 如何切换用户？

A: 当前版本支持通过API切换用户：
```javascript
await callBackend("switchUser", "new_user_id");
```
未来版本将提供图形化登录界面。

### Q8: 多用户时模型需要重复下载吗？

A: **不需要！** 模型存储在 `data/public/models/`，所有用户共享。切换用户时不会重复下载。
