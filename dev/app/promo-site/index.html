核心特性

🖥️ 双端体验

同时提供专业的终端 TUI 界面和现代化的 Vue3 + Electron 桌面图形界面，满足不同开发习惯。

🤖 全能 Agent

内置 Bash 执行、文件精准编辑、代码搜索等核心工具，支持多步迭代与复杂任务处理。

⚡ 高度可定制

通过 .env 轻松配置 API 端点，完美兼容 MiniMax、OpenRouter 等第三方服务，摆脱官方限制。

🛠️ 稳定性修复

深度解决原始源码在本地环境下的启动卡死、按键失效等问题，确保生产级稳定运行。

一键安装

需要安装 Bun >= 1.1 或 Node.js >= 18

# 克隆项目
git clone https://github.com/your-repo/claude-code-tudou.git
# 安装依赖并启动
cd claude-code-tudou && npm install && npm run desktop
