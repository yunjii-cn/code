核心功能

🚀 多模型支持

无缝集成 Anthropic Claude、AWS Bedrock 等多种主流大模型，根据任务需求智能切换，提供最佳代码生成与建议。

💻 桌面端体验

基于 Electron 构建的现代化桌面应用，支持图形化界面交互，提供更直观的代码审查、文件编辑与任务管理体验。

🛡️ 本地恢复与安全

内置本地会话恢复机制，确保工作进度不丢失。结合沙箱运行时与权限管理，保障代码与数据安全。

实时追踪 API 调用成本，提供可视化图表与阈值提醒，帮助团队和个人有效管理 AI 使用预算。

🔌 MCP 协议支持

全面支持 Model Context Protocol，轻松扩展上下文能力，连接数据库、文件系统与其他开发工具。

⚡ 高效 CLI 工具

保留强大的命令行交互模式，支持 Ink 渲染的 TUI 界面，为习惯终端的开发者提供流畅的操作体验。
